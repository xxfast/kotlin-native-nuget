# A materialisation throw inside a `Flow<T>`'s `onNext` callback kills the host process

> Extracted verbatim from `ROADMAP.md` (Phase 6).

**A materialisation throw inside a `Flow<T>`'s `onNext` callback crosses the unmanaged reverse-P/Invoke boundary and kills the host process, instead of faulting the channel like the sibling `onError` path does.** `CirFlowRenderer.kt:44-49` renders `KotlinFlowEnumerator<T>.onNext` as a bare `T value = NugetMarshal.FromHandle<T>(itemPtr);` with no try/catch around the native callback body, while the `onError` callback three lines below it (`CirFlowRenderer.kt:56-59`) wraps its work and reports failure via `_channel.Writer.TryComplete(ex)`, which `MoveNextAsync` surfaces as an ordinary awaited exception. Any exception `FromHandle<T>`/`Materialize<T>` throws inside `onNext` (a factory-registry miss, for instance) instead unwinds through the native-to-managed callback thunk with no managed catch, aborting the process rather than faulting the `IAsyncEnumerable<T>`. Went unnoticed because no existing fixture had ever driven `onNext` down a throwing path: enum elements (the `StateFlow<SomeEnum>`/`FromHandle<T>` item above) are avoided by every fixture that hits them, and no other `Flow<T>` element type reached `Materialize<T>`'s throwing branch until now. Discovered alongside [#40](https://github.com/xxfast/kotlin-native-nuget/issues/40): while the sealed-base factory-registry entry was still missing, the `await foreach` tests over `Loader.History` (`IntegrationTests/Issue40Tests.cs`) crashed the xunit host outright ("Test Run Aborted") rather than failing the assertion, because `onNext`'s `Materialize<T>` throw had no catch to route into the channel. Verified by source reading (`CirFlowRenderer.kt:44-49` vs `:56-59`) and by the observed host-crash symptom before the registry fix landed; not independently re-reproduced after the fix, since the fix removed this fixture's own path to it. Not fixed here: it is a `Flow<T>` error-handling gap (ADR-026), not part of the sealed-base registry fix.
