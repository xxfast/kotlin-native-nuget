TITLE: Return a lambda as a BCL delegate on every owner and widen the callback vocabulary (ADR-239)

A function returning a lambda only bound at the top level, typed as a wrapper (`KotlinFunc<A, R>`, `KotlinAction<A>`, `KotlinSuspendFunc<A, R>`) with a `Dispose` obligation. The same member on a class, an `object`, a companion, an enum, an interface, a sealed arm, a generic class or an extension, and any `suspend` lambda return, was named `SKIPPED_UNSUPPORTED_RETURN`. Callbacks were narrow too: a lambda parameter, a stored `add`/`remove` pair, a returned lambda and a lambda property carried `Unit`, a primitive, `String` or a class handle, and a `Char`, nullable, collection or `ByteArray` payload was a named skip or a host crash. Now every owner returns the BCL delegate ADR-236 gave a property, `suspend` and nullable included, and the five callback routes share the plan's payload and result vocabulary.

```kotlin
object Bleachers {
  var stomps: Int = 0

  fun cheer(): (String) -> String = { who -> "the bleachers cheer $who" }

  fun stomp(): (Int) -> Unit = { times -> stomps += times }

  fun chant(): suspend (String) -> String = { who ->
    delay(1.milliseconds)
    "the bleachers chant $who"
  }

  fun maybeCheer(loud: Boolean): ((String) -> String)? =
    if (loud) { who -> "the bleachers roar $who" } else null
}

class Scorecard(val judge: String) {
  // A stored add/remove pair, the hand-written callback route, with an enum result.
  private val judges: MutableList<(String) -> Spirit> = mutableListOf()

  fun addJudge(pick: (String) -> Spirit) {
    judges.add(pick)
  }

  fun removeJudge(pick: (String) -> Spirit) {
    judges.remove(pick)
  }

  /** Every stored judge's verdict on [judge], joined. */
  fun verdicts(): String = judges.joinToString { pick -> pick(judge).name }

  // Payloads beyond a primitive, `String`, enum or handle, each described back by the C# delegate.
  fun initialOf(describe: (Char) -> String): String = describe(judge.first())
  fun scores(describe: (Int?) -> String): String = "${describe(null)} then ${describe(7)}"
  fun roster(count: (List<String>) -> Int): Int = count(listOf(judge, "Oreo"))
  fun bytesOf(count: (ByteArray) -> Int): Int = count(byteArrayOf(1, 2, 3))
}
```

```csharp
Func<string, string> cheer = Bleachers.Cheer();
Action<int> stomp = Bleachers.Stomp();
Func<string, CancellationToken, Task<string>> chant = Bleachers.Chant();
Func<string, string>? quiet = Bleachers.MaybeCheer(false); // null

cheer.Invoke("Oreo"); // "the bleachers cheer Oreo"
stomp.Invoke(2); // Bleachers.Stomps went up by 2
await chant.Invoke("Mylo", CancellationToken.None); // "the bleachers chant Mylo"

using Scorecard card = new("Mylo");

using (IDisposable hyped = card.AddJudge(_ => Spirit.Hyped))
using (IDisposable calm = card.AddJudge(who => who == "Mylo" ? Spirit.Calm : Spirit.Hyped))
{
    card.Verdicts(); // "HYPED, CALM"
}
card.Verdicts(); // ""

card.InitialOf(c => $"got {c}"); // "got M"
card.Scores(n => n?.ToString() ?? "none"); // "none then 7"
card.Roster(names => names.Count); // 2
card.BytesOf(bytes => bytes.Length); // 3
```

**Breaking** for every function that already returned a lambda:

| Before | After |
|---|---|
| `KotlinFunc<A, R>` return | `Func<A, R>` |
| `KotlinAction<A>` return | `Action<A>` |
| `KotlinSuspendFunc<A, R>` / `KotlinSuspendAction<A>` return | `Func<A, CancellationToken, Task<R>>` / `Func<A, CancellationToken, Task>` |
| `using var f = Obj.Fn();` | `var f = Obj.Fn();` (a delegate isn't `IDisposable`, nothing to dispose) |
| `await f.InvokeAsync(args)` | `await f(args, token)`, `CancellationToken.None` when there's none |
| `typeof(KotlinFunc<int, int>)` as the return type | `typeof(Func<int, int>)` |
| the same member on a class, `object`, companion, enum, interface, sealed arm, generic class or extension: `SKIPPED_UNSUPPORTED_RETURN` | binds as above |

Each return mints a fresh handle the delegate's target releases on collection, so a returned delegate you drop is released by the GC. A delegate a C# interface implementation returns is minted into a Kotlin lambda, and Kotlin dropping it frees the delegate's key. The wrapper classes stay in the generated file as plumbing, but no generated member returns or takes them.

The additive half: a plain lambda parameter, a `suspend` lambda parameter, a stored pair, a returned lambda and a lambda property now take the vocabulary the callable plan already uses for a method parameter and return. Payload and result: `Char`, a nullable of any admitted type, `List`/`Set`/`Map`, `ByteArray`, `Instant`/`Duration`/`Uuid`, a value class, a type parameter and a bound C# interface (`IFeedable`); a result can also be an enum or an exported class handle; `Throwable` crosses as `System.Exception` in either slot, a `Throwable?` payload and a `suspend` result (`Func<int, CancellationToken, Task<Exception>>`) included. A stored pair binds with a result (`addJudge`), on a generic owner (`Shaker<T>.addShake`, `Shaker<T>.addCounter`) and on a generic sealed arm carrying the arm's `T` (`Pyramid.Tier<T>.addClimber`), which removes the ADR-199 erased-lambda refusal; an ADR-039 subscription pair binds on a generic owner too (`Stand<T>.addWave`). A nullable `suspend` lambda parameter (`Countdown.maybeLater`) binds, and a C# `null` reaches Kotlin as `null`.

Three shapes stay refused by standing rules, each pinned by name: a lambda with four or more parameters (a lambda crosses with at most three on every callback route), a `Pair` or `IntArray` payload (mapped at no position), and an `Any` payload, which ADR-237 binds in its own PR.
