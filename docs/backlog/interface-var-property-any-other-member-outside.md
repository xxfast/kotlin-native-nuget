# An interface with a `var` property (or any other member outside [ADR-084](docs/adr/084-csharp-implemented-interfaces.md)'s v1 slot vocabulary: an…

> Extracted verbatim from `ROADMAP.md` (Tooling & Test Integrity) in the 2026-08-31 roadmap slim-down.

**An interface with a `var` property (or any other member outside [ADR-084](docs/adr/084-csharp-implemented-interfaces.md)'s v1 slot vocabulary: an object/collection-typed slot, `suspend`, generics) silently gets no bridge factory at all.** `ForwardInterfaceBridgePlanner.kt` plans such an interface to `null`: no `{prefix}_bridge_create` export, no bridge state, nothing in the KSP build log naming which member disqualified it or which interface was skipped. A C# class implementing that interface and passed at a parameter position falls through to `NugetMarshal.HandleOf`'s original `NotSupportedException` (ADR-040's v1 boundary), with a message that names only the C# type, never the reason. Verified by reading `ForwardInterfaceBridgePlanner.kt`'s "plans to `null`" branch and the Tier 1 skip cell during ADR-084 research; would fit the [ADR-064](docs/adr/064-forward-unsupported-declaration-diagnostics.md) named-skip family (a `SKIPPED_UNSUPPORTED_INTERFACE_MEMBER`-shaped diagnostic naming the interface, the disqualifying member, and why) rather than staying a silent absence. Discovered alongside [ADR-084](docs/adr/084-csharp-implemented-interfaces.md).

**Confirmed unchanged by [ADR-174](docs/adr/174-interface-async-members.md) (2026-09-28):** a `suspend`, `Flow`, or `StateFlow` member is exactly this case for the *reverse* direction. ADR-174 only declares such a member on the forward `I<Name>`; `ForwardInterfaceBridgePlanner.slotOf`/`plan` still return `null` for the whole interface (`ForwardInterfaceBridgePlanner.kt:183`, `:133`), so a C#-implemented `IFeed` passed to a Kotlin parameter still throws at `NugetMarshal.HandleOf`, silently, with `kspWarnings` and `NugetDiagnostics.json` both empty. Verified by a Tier 1 spike on `interface Feed { suspend fun fetch(...); fun ticks(): Flow<Int> }`, not re-verified against the shipped ADR-174 code.
