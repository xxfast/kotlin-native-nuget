TITLE: Cross a generic value class at every erased position (ADR-228)

A generic value class at an erased position (`Box<Sticker<Int>>`, a lambda payload or result, a `Flow` or `StateFlow` element, an awaited `suspend` result) was a named skip. ADR-171's box/unbox pair is keyed by the C# runtime type, and `Sticker<int>` and `Sticker<Cat>` are different keys, while an own-`T` `Sticker<T>` only has a closed type at run time. But Kotlin/Native boxes every instantiation as one runtime class, so one pair per generic value class serves them all. The struct implements an internal `INugetGenericValue` that `Wrap<T>` dispatches on, and reads go through ADR-199's per-closed-type `NugetFactory` slot.

```kotlin
fun boxed(): Box<Sticker<Int>> = Box(Sticker(1))

fun <T> boxedOf(value: T): Box<Sticker<T>> = Box(Sticker(value))

class StickerCourier(val desk: String) {
  val onSticker: (Sticker<String>) -> Sticker<Int> = { Sticker(it.value.length) }

  suspend fun bumpLater(sticker: Sticker<Int>): Sticker<Int> {
    yield()
    return Sticker(sticker.value + 1)
  }
}
```

```csharp
using Box<Sticker<int>> box = StickerSwaps.Boxed();           // box.Value == Sticker<int>(1)
using Box<Sticker<ulong>> treats = StickerSwaps.BoxedOf(7UL); // treats.Value.Value == 7UL

using var courier = new StickerCourier("Oreo's desk");
using KotlinFunc<Sticker<string>, Sticker<int>> onSticker = courier.OnSticker;
onSticker.Invoke(new Sticker<string>("Oreo"));                // Sticker<int>(4)
await courier.BumpLaterAsync(new Sticker<int>(5));            // Sticker<int>(6)
```

It's one box/unbox export pair per generic value class, not per instantiation. The read side needs `NugetRegister()` to have filled the slot for that closed type, and the static constructor isn't enough: a Kotlin-made `Sticker<ulong>` can be read before C# ever constructs one, which is what the row above proves. So every generated member that hands one out at an erased position calls it; the call is static, so it stays trimming- and AOT-safe. Root-cause fix for a silent drop: a generic value class's properties skipped the unrouted-position naming pass, so `val glow: StateFlow<T>` vanished with no diagnostic. Every property goes through the one pass now, and `Glow`, `Chirps` and the struct's `Flow` members bind on the ADR-230 route. `value class Nick(val name: String?)` joins ADR-171's pair, so `Nick(null)` and `null` stay distinct at an erased position. Value-class parameters on the legacy suspend and `Flow` routes and value-class callback payloads and results now bind too, which binds members that used to skip.
