TITLE: Bind a `Flow` on every owner with no instance scope (ADR-230)

A `Flow`, `StateFlow`, `SharedFlow` or one of the mutable forms only bound where a C# owner could hold the scope the collection runs on: a class, an interface, a sealed base or arm, with `DisposeAsync()` on the owner cancelling every live collection. The top level, an `object`, a companion, an enum body or companion and a value class all dropped the member as `SKIPPED_UNSUPPORTED_RETURN` or `SKIPPED_UNSUPPORTED_PROPERTY`. None of those has anything to dispose, and the runtime already collects on a root scope when there's no scope handle, so the flow route now works over a receiver with no handle and no scope slot.

```kotlin
object PurrClock {
  val hour: MutableStateFlow<Int> = hourState
  fun ticks(count: Int): Flow<Int> = flow { repeat(count) { emit(it) } }
  fun <T> echo(value: T, times: Int): Flow<T> = flow { repeat(times) { emit(value) } }
}

val bedtime: MutableStateFlow<Int> = MutableStateFlow(21)
```

```csharp
using KotlinFlow<int> ticks = PurrClock.Ticks(3);
await foreach (int tick in ticks) { /* 0, 1, 2 */ }

using KotlinMutableStateFlow<int> hour = PurrClock.Hour;
hour.Value = 6;

using KotlinMutableStateFlow<int> bedtime = Chimes.Bedtime;
bedtime.Value = 22;
```

Each collection runs on its own root scope and only its enumerator ends it (completion, the token, `break`, `DisposeAsync()`), since there's no owner to dispose. A cold static flow holds no handle until you enumerate it; a held `MutableStateFlow` or `MutableSharedFlow` owns the flow's handle and you dispose it. An awaited `MutableStateFlow` from a `suspend` member is now settable on every static owner; at the top level it used to be read-only. An enum body's flow property comes out as a C# 14 `extension(Chime receiver)` property. A `var` flow property is still get-only and names its dropped setter, as on a class.

Fixes a naming bug on the way: diagnostics and the planner's lookups called a named companion's members `Owner.Companion.x` whatever the companion was called. They now read `Owner.<Name>.x`.
