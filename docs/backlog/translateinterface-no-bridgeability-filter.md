# `translateInterface` emits every public interface member with no bridgeability filter, so an unbridgeable interface member yields CS0535 in the generated C#.

> Extracted verbatim from `ROADMAP.md` (Phase 4: Rich type support) in the 2026-08-31 roadmap slim-down.

**`translateInterface` emits every public interface member with no bridgeability filter, so an unbridgeable interface member yields CS0535 in the generated C#.** Pre-existing, on the interface path (not the class path the defaulted-member fix above closed): unlike a class member, which is skipped with a named `SKIPPED_*` diagnostic when its type isn't bridgeable, an interface's member list is translated unconditionally, so a member the forward direction cannot express (a generic method, a member typed to something unsupported) still lands on the generated `IFoo` and on any implementing class's declared interface list, with nothing able to satisfy it. Verified by source during the defaulted-interface-member fix (item above), which had to reconcile `CirClassTranslator`'s and the two `Forward*Planner`s' definitions of "has a superclass" and found this adjacent, unguarded path in the same file. Not reproduced by a fixture.
