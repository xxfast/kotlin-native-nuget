TITLE: Cross `kotlin.Any` as `object` and erase a member-level `<R>` (ADR-237)

`kotlin.Any` had no C# spelling. A parameter, result, property, collection element, lambda payload or `Flow` element typed `Any` was a named skip, and so was anything that reduced to it: a star projection like `Box<*>` or `Flow<*>`, and the erased `Any?` behind a type parameter. An interface with its own member-level `<R>` (`fun <R> sniff(f: (T) -> R): R`) couldn't be implemented in C# at all; ADR-222 and ADR-224 called it impossible. Now `Any` is `object` and `Any?` is `object?` at every position, a Kotlin value arrives as its runtime C# value, a C# object goes in as the matching Kotlin value, and the member-level `<R>` is erased to `object?` on the C# interface.

```kotlin
class Mouse(val name: String) {
  fun squeak(): String = "$name squeaks"
}

/** A non-null `Any` in and out, handed back as is. */
fun stash(value: Any): Any = value

interface Sniffer<T> {
  val item: T

  fun <R> sniff(f: (T) -> R): R
}

/** Kotlin calls the C# sniffer at `R = Int` and at `R = String`. */
fun sniffing(sniffer: Sniffer<String>): String =
  "${sniffer.sniff { it.length } + 1} ${sniffer.sniff { it.uppercase() }}"
```

```csharp
internal sealed class Whiskers(string item) : ISniffer<string>
{
    public string Item { get; } = item;

    public object? Sniff(Func<string, object?> f) => f(Item);

    public void Dispose() { }
}

Hoarding.Stash(5); // a boxed int, 5
Hoarding.Stash(Fur.Caramel); // Fur.Caramel

using var mouse = new Mouse("Oreo");
using var back = (Mouse)Hoarding.Stash(mouse);
back.Squeak(); // "Oreo squeaks"

Hoarding.Sniffing(new Whiskers("Mylo")); // "5 MYLO"

using ISniffer<string> snout = Hoarding.Snout("Oreo");
snout.Sniff(name => name.Length); // a boxed int, 4
snout.Sniff(name => name.ToUpperInvariant()); // "OREO"
```

Every Kotlin value that crosses an `Any` position is a box. The runtime exports a type tag for it, the C# `object` read dispatches on the tag, and a handle-backed value is rebuilt from a `KotlinTypes` factory table keyed by the Kotlin class name. A C# object Kotlin holds is a `NugetManagedObject`, released through a fail-fast `FreeManaged` thunk with no error slot. On a C#-implemented interface a member's own `<R>` is declared erased (`object?`, or its single bound) and Kotlin calls the C# implementation at `R = Any?`; a Kotlin class implementing the interface keeps its typed `Sniff<R>` and implements the erased one explicitly. A `reified` parameter, two bounds, or a bound naming another type parameter keep a named refusal. A star projection reads at the bound, so `Satchel<*>` is `Satchel<object?>` and `Flow<*>` is `KotlinFlow<object?>`.

A generic value class at an `Any` position (`value class Bow<T>(val ribbon: T)`) crosses as its own struct through an `INugetGenericValue` box and unbox pair, and reads back as `Bow<object?>`, never the `Bow<string>` that went in; its `init` runs in Kotlin and a failure is an `ArgumentException`. A hand-written C# implementer of an interface with a member-level `<R>` now has to implement the erased member the interface used to omit. Fixed along the way: `kotlin.Result` is refused explicitly as a value class (its internal `value` would otherwise plan as `object` and generate Kotlin that doesn't compile), and a `Unit` property is a named `SKIPPED_UNSUPPORTED_PROPERTY` instead of a `public void X { get; }` that failed with CS1547. The Tier 1 C# compile now allows unsafe code, since the `object` read needs an unmanaged function pointer.
