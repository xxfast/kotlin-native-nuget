TITLE: Bind a generic value class own `T` whatever its bound (ADR-220)

ADR-220 refused a function's own `T` inside `Sticker<T>` when its bound needed the ADR-198 trampoline (`T : Comparable<T>`, `T : Enum<T>`, an intersection). The reasoning was that the unwrap and re-wrap sat outside the trampoline's type variable. They don't: the trampoline wraps the export's whole body, so the unwrap, the call and the re-wrap all run inside it. Now a bounded own `T` binds inside the struct, on top-level functions and on class members.

```kotlin
value class Sticker<T>(val value: T) {
  init {
    require(value != -1) { "Mylo peeled this sticker already" }
  }
}

fun <T : Comparable<T>> ranked(sticker: Sticker<T>): T = sticker.value

fun <T : Comparable<T>> higher(a: Sticker<T>, b: Sticker<T>): Sticker<T> =
  if (a.value >= b.value) a else b

fun <T : Enum<T>> napOf(sticker: Sticker<T>): Sticker<T> = sticker

fun <T> loudest(sticker: Sticker<T>): Sticker<T> where T : CharSequence, T : Comparable<T> = sticker
```

```csharp
Stickers.Higher(new Sticker<string>("Mylo"), new Sticker<string>("Oreo")); // Sticker<string>("Oreo")
Stickers.NapOf(new Sticker<Mood>(Mood.Grumpy)).Value;                     // Mood.Grumpy
Stickers.Loudest(new Sticker<string>("Oreo"));                            // Sticker<string>("Oreo")
Stickers.Ranked(new Sticker<int>(-1));                                    // throws KotlinArgumentException
```

`T : Comparable<T>` doesn't need the trampoline at all: `Comparable` is `in`, so the erased `Comparable<Any?>` is within the bound. C# gets `where T : notnull` and Kotlin checks the bound. `T : Enum<T>` gets `where T : struct, global::System.Enum` and runs through the trampoline, crossing as an ordinal; an intersection goes through the ADR-217 trampoline. Two fixes fell out: an intersection-bound unwrap failed the Kotlin compile (`readThrough` skipped `ValueClass`), and the `default(Sticker<T>)` guard emitted CS0019 for a `struct`-constrained `T`. A default `Sticker<Mood>` holds the enum's first entry, so that case has no guard.
