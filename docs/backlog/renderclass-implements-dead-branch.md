# Suspected dead branch: `CirClassRenderer.renderClass`'s `implements` `when` has an `else -> " : INugetHandle"` case that looks unreachable.

> Extracted verbatim from `ROADMAP.md` (Phase 3: Basic type support) in the 2026-08-31 roadmap slim-down.

**Suspected dead branch: `CirClassRenderer.renderClass`'s `implements` `when` has an `else -> " : INugetHandle"` case that looks unreachable.** The `when` (`CirClassRenderer.kt:193-199`) falls to that branch only when `cls.superClass == null`, `cls.interfaces.isEmpty()`, and `cls.disposable == false`. `CirClass.disposable` (`CirModel.kt:58`) defaults to `true`, and no production call site in `nuget-processor/src/main/kotlin` ever passes `disposable = false` for a `superClass == null` class (verified by grep: `disposable = false` appears nowhere in main source), so every real `CirClass` with no superclass and no interfaces should take the `cls.disposable` branch above it instead. Not verified by execution, only by reading the predicate and its call sites; a test-only `CirClass` builder could still exercise the branch deliberately. Discovered while auditing `CirClassRenderer.kt`'s `implements` list for [ADR-094](docs/adr/094-reflection-free-generic-dispatch.md), which added the `INugetHandle` interface to every branch of this `when`; not fixed here, since removing dead configurability is a separate, scoped cleanup.
