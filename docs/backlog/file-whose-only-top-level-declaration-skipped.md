# A file whose only top-level declaration is skipped still emits an empty, pointless `public static partial class X { }` stub into `Interop.cs`.

> Extracted verbatim from `ROADMAP.md` (Phase 3: Basic type support) in the 2026-08-31 roadmap slim-down.

**A file whose only top-level declaration is skipped still emits an empty, pointless `public static partial class X { }` stub into `Interop.cs`.** `CirTranslator.kt:165` (and the mirrored suspend/generic/property loops) unconditionally emits a `CirStaticClass` for every file that contributed at least one top-level function or property, even when every member ends up `Skipped` and `members` is empty. Symptom: a file whose only top-level declaration is dropped by **any** `SKIPPED_*` diagnostic (a `Map`/`Set` parameter, a nullable-`Boolean` return, or the new `SKIPPED_ACTUAL_TYPEALIAS_TARGET`) still emits the stub. Cosmetic only: it compiles, and carries no `DllImport`s, so there's no ABI-contract exposure. Verified by direct inspection of the generated `Interop.cs`. Predates and is orthogonal to [ADR-074](docs/adr/074-expect-actual-declarations.md) (Forward `expect`/`actual` declarations); it surfaced because that feature's alias-target diagnostic cell was the first thing to hit it.
