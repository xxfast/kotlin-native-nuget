# A sealed collection method return, or a sealed-typed parameter, vanishes from C# with no diagnostic

> Extracted verbatim from `ROADMAP.md` (Phase 3).

**`fun x(): List<Shape>` does not "skip named" the way the old ROADMAP line claimed; it is dropped from the generated C# with no warning at all.** `ForwardCallablePlanner.kt` (~line 2262) recurses `skipReason` down to the collection element and lands on `ForwardPlanSkipReason.SEALED_PROTOCOL`, a `droppedFromCSharp = false` legacy-route deferral that never reaches `NugetProcessor.kt`'s `droppedCallables`, so no `SKIPPED_*` diagnostic ever fires for it. `exports/FunctionExports.kt:26` only re-emits a *bare* sealed return (`returnDecl.modifiers.contains(SEALED)`, which is `false` for `kotlin.collections.List`), so the collection-returning function is silently absent from the generated `Interop.cs`. This is the same defect class as the existing ROADMAP line "A class method returning a sealed type is silently dropped, with no diagnostic": a legacy route that neither binds nor warns. Established by reading `ForwardCallablePlanner.kt` and `FunctionExports.kt` only, not built or reproduced with a fixture. Discovered alongside [ADR-105](docs/adr/105-sealed-property-position.md) (issue [#54](https://github.com/xxfast/kotlin-native-nuget/issues/54)).

**A bare sealed type at a parameter position, `fun f(shape: Shape)` or a constructor with sealed-typed parameters, drops the same way: silently, with no diagnostic, the same `SEALED_PROTOCOL` (`droppedFromCSharp = false`) deferral class.** The `#54` fixture's own generated output is the concrete evidence: `Issue54Drawing`'s primary constructor takes four sealed-typed parameters (`shape: Issue54Shape`, `maybe: Issue54Shape?`, `shapes: List<Issue54Shape>`, `current: Issue54Shape`), and the generated `Issue54Drawing` class carries only the always-emitted `internal Issue54Drawing(IntPtr handle)` wrapper constructor, no public one; the `packNuget` log for that fixture named all four *property* skips (pre-ADR-105) but named no constructor skip at all. Established by that fixture's generated output plus source reading, not chased.
