TITLE: Bind a `suspend` member on every static owner (ADR-229)

A `suspend` member only bound where C# could hold its coroutine scope: a class, a sealed base or arm, and the top level (which launches a root scope per call). An `object`, a companion (default or named), a suspend extension, an enum body or enum companion, and a value class all dropped theirs as `SKIPPED_UNSUPPORTED_COMBINATION`. None of those has anything a `Dispose()` could cancel, which is exactly the top-level case, so the top-level route now generalises over the receiver: one `_async` export per member, a fresh root scope per call, no C# scope handle.

```kotlin
object Siesta {
  suspend fun minutesFor(name: String): Int {
    delay(1.milliseconds)
    return name.length * 10
  }
}

class Swing(val sleeper: String) {
  companion object {
    suspend fun hang(sleeper: String): Swing { /* ... */ }
  }
}

suspend fun Swing.rock(times: Int): String = "$sleeper rocked $times times"
```

```csharp
int minutes = await Siesta.MinutesForAsync("Oreo");           // 40
await using Swing mylo = await Swing.HangAsync("Mylo");
string rocked = await mylo.RockAsync(2);                      // "Mylo rocked 2 times"
string spot = await NapSpot.Windowsill.ClaimAsync("Oreo");    // enum receiver crosses as its ordinal
```

Cancellation is only per call, through the `CancellationToken`, since there's no owner to dispose. A companion `suspend fun sway(times: Int)` next to an instance `suspend fun sway()` is a legal static/instance overload pair in C#; if the parameter lists match it's `ERROR_CSHARP_SIGNATURE_COLLISION`, like any other clash. The new `_async` exports land in the ABI contract with the other legacy routes.
