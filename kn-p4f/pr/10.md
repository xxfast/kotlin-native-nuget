TITLE: Bind a generic value class's members, properties and constructors (ADR-225)

ADR-220 rendered `Sticker<T>` as a bare positional record struct. Every member, property and secondary constructor of a generic value class was a named skip, because the value-class member route had no receiver spelling for a type parameter. A member with its own `<R>` was refused on every value class, generic or not. Kotlin erases a generic value class to one runtime class, so now one export per member serves every instantiation: the receiver crosses as the underlying at the class's own `T`, and Kotlin re-wraps it inside the export.

```kotlin
value class Sticker<T>(val value: T) {
  init {
    require(value != -1) { "Mylo peeled this sticker already" }
  }

  constructor(oreo: T, mylo: T, pickMylo: Boolean) : this(if (pickMylo) mylo else oreo)

  val peeled: T get() = value

  fun swap(other: T): Sticker<T> = Sticker(other)

  fun <R> pairWith(other: R): String = "$value+$other"

  suspend fun peelLater(): T {
    yield()
    return value
  }
}
```

```csharp
new Sticker<string>("Mylo").Peeled;          // "Mylo"
new Sticker<int>(7).Swap(8);                 // Sticker<int>(8)
new Sticker<string>("Oreo").PairWith(7);     // "Oreo+7"
await new Sticker<int>(3).PeelLaterAsync();  // 3
new Sticker<int>(1, 2, true).Value;          // 2
new Sticker<int>(3).Swap(-1);                // throws KotlinArgumentException
new Sticker<int>(3, -1, true);               // throws KotlinArgumentException
new Sticker<int>(-1).Value;                  // -1, the positional constructor doesn't run init
```

Members ride a new `VALUE_CLASS_MEMBER` origin with an error slot. The non-generic value-class projection has none, so a throwing member or a failing `init` on the re-wrapped receiver would otherwise abort the process. The struct header carries no `where` for the class's bound, so `new Doze<int>(3).Label()` compiles and throws `KotlinInvalidCastException` from Kotlin (the receiver read's `Enum` cast) and the process carries on. A `T : Any` bound is refused earlier, in C#: `default(Badge<string>).Describe()` throws `ArgumentException`. Members with their own `<R>` now bind on any value class, the non-generic `Collar` included, with `R` de-clashed from the struct's `T`. The phantom `Decal<T>` re-wraps as `Decal<Nothing>`; that `Nothing` satisfies every bound was checked in a `kotlinc-native` 2.4.20 spike (the repo pins 2.4.10) and is covered here by the `Decal<Cat>` rows.
