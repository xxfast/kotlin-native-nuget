TITLE: Fill a nested open generic factory at every position (ADR-216)

A member's own result already filled the `NugetFactory<X>` slot for an open instantiation it nests, so `Basket<Basket<T>>` read fine there. Anywhere else (a getter, a parameter, a list or map element, a callback argument, a `Flow` element, a returned lambda, a `suspend` result, a `Result` payload) nothing filled it, and reading the inner value before you'd ever held a `Basket<short>` threw `NotSupportedException`. Now every body that brings a Kotlin value across fills the slots for its whole signature, at any depth.

```kotlin
class Satchel<T>(val item: T) {
  val nested: Basket<Basket<T>> = Basket(Basket(item))
  val baskets: List<Basket<T>> = listOf(Basket(item), Basket(item))
}
```

```csharp
using var satchel = new Satchel<short>(7);
using Basket<Basket<short>> nested = satchel.Nested;
using Basket<short> inner = nested.Item; // no prior Basket<short> needed
```

A generic abstract class now gets its own static constructor and fills by constructing its backing class, so `Basket<Cabinet<T>>` reads before you hold a `Cabinet<int>`. A nested generic sealed type fills through `FromHandle`. A bare handle the member constructs itself only fills what it nests (its own static constructor covers the outer slot); a callback argument, `Flow` element, returned lambda or collection fills the outer one too. A fill only stores a factory: no handle, no P/Invoke.
