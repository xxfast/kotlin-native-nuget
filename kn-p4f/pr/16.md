TITLE: Map a value class over a stdlib, handle or collection type (ADR-235)

`Instant`, `Duration`, `Uuid`, `ByteArray`, collections, other value classes and plain interfaces all had a wire at every ordinary position, but a value class over one of them was refused by name. So `value class SnoozeSpan(val span: Duration)` wasn't declared and every member typed with it was a named skip. Bare `List<Uuid>`, `Set<Duration>` and `Map<Instant, Uuid>` were declined as collection components too. Now each one binds as a record struct over its underlying's C# spelling and crosses on that underlying's wire.

```kotlin
value class SnoozeSpan(val span: Duration) {
  constructor(minutes: Int) : this(minutes.minutes)

  init {
    require(!span.isNegative()) { "a snooze cannot be negative" }
  }

  fun doubled(): SnoozeSpan = SnoozeSpan(span * 2)

  val minutes: Long get() = span.inWholeMinutes
}

value class PawPrint(val pads: ByteArray) {
  init {
    require(pads.isNotEmpty()) { "a paw print needs at least one pad" }
  }

  val padCount: Int get() = pads.size
}

fun echoPaw(paw: PawPrint): PawPrint = paw
fun napsByChip(): Map<Uuid, Duration> = mapOf(OREO_CHIP to 20.minutes, MYLO_CHIP to 45.minutes)
```

```csharp
var snooze = new SnoozeSpan(TimeSpan.FromMinutes(25));
snooze.Doubled().Span;    // 00:50:00
snooze.Minutes;           // 25
new SnoozeSpan(20).Span;  // 00:20:00, built in Kotlin

new SnoozeSpan(TimeSpan.FromMinutes(-1)).Doubled(); // throws KotlinArgumentException
FurcoatSample.EchoPaw(new PawPrint(new byte[] { 9, 8, 7 })).Pads; // [9, 8, 7]
FurcoatSample.EchoPaw(default); // throws ArgumentException naming PawPrint
```

`init` runs in Kotlin on the re-wrap, so a bad struct fails at the crossing. Members, properties and secondary constructors on these value classes ride the error-slot route: the receiver crosses on the underlying's wire, and a handle-wired one (`ByteArray`, collection, interface) is minted before the call and released in a `finally`. `default(V)` of a reference underlying (`PawPrint`, `ToyBasket`, `PurrVoice`, and nested ones like `PawCast`) throws `ArgumentException` before the call; `default` of a `DateTimeOffset`, `TimeSpan` or `Guid` struct crosses and `init` decides. A `byte[]` or list struct still compares by reference here. An interface struct hands a C# implementation back as the same instance, and a Kotlin-backed `IRumbler` read out of one is yours to dispose.
