TITLE: Map a generic value class over a collection of its own `T` (ADR-235)

A generic value class over a `List<T>`, `Set<T>` or `Map<K, T>` was refused as "wraps kotlin.collections.List, which no value-class wire carries", and every member typed with it was skipped. `Opt<T>(val value: T?)` closed at `Int` generated C# that did not compile. Now `Bundle<T>` is one `readonly record struct Bundle<T>(IReadOnlyList<T> Items)` and binds at every position: parameter, result, property, constructor, nullable outer, collection element, own members, a function's own `T`, a `Box`, a lambda, a `Flow` element, an awaited result, a `MutableStateFlow` write.

```kotlin
value class Bundle<T>(val items: List<T>) {
  init {
    require(items.size <= 3) { "Mylo cannot carry more than three" }
  }
  // ...
}

value class MaybeBundle<T>(val items: List<T>?)

value class Gappy<T>(val items: List<T?>)

value class Opt<T>(val value: T?)

value class TreatTin(val treats: List<Int>?)

fun <T> wrap(items: List<T>): Bundle<T> = Bundle(items)
```

```csharp
Bundle<int> packed = Bundles.Pack(new[] { 1, 2 });
Bundles.Total(packed); // 3
Bundles.Pack(new[] { 1, 2, 3, 4 }); // KotlinArgumentException, init runs at the crossing
Bundles.Unwrap<string>(Bundles.Wrap<string>(new[] { "mouse" })); // ["mouse"]

Bundles.MaybeBundleSize(new MaybeBundle<int>(null)); // -1
Bundles.MaybeBundleSize(new MaybeBundle<int>(Array.Empty<int>())); // 0
Bundles.Gappy().Items; // [1, null, 3]
Bundles.Gaps(new Gappy<int?>(new int?[] { null, 4, null })); // 2

Optionals.OptState(new Opt<int?>(null)); // "none"
Optionals.OptState(new Opt<int?>(5)); // "5"
Optionals.TinState(null); // "absent"
Optionals.TinState(new TreatTin(null)); // "empty"
```

The class takes ADR-235's collection-underlying wire with the use site substituted, so `Bundle<Int>` is a plain collection value class over `List<Int>` to both halves, and an own `T` rides ADR-212's boxed element wire. Erased positions (a `Box`, a flow element, an awaited result) cross through ADR-228's box pair, registered once per closed type. A nullable collection underlying is now a wire for every value class, generic or not, so `TreatTin(null)` stays distinct from `null` as a parameter, a result, under `?` and inside a `Box`.

C# reads an unconstrained `T?` as `T` for a value type, so the type argument carries the nullability: `Opt<Int>` is `Opt<int?>` and `Gappy<Int>` is `Gappy<int?>`; `Opt<String>` stays `Opt<string>`. A generic value class's `Flow` member used to reference a `receiverHandle` it never declared (CS0103); the flow now mints the receiver's handle from its own copy of the struct and releases it after the call.
