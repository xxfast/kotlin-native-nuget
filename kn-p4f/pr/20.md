TITLE: Bind an extension on every receiver, sync and `suspend` (ADR-238)

An extension bound only on the receivers ADR-132 listed, and each route kept its own list. A generic receiver (`Bindle<T>`), a bare `T` and a star projection (`Bindle<*>`) were named skips. A member extension inside a class lost its receiver, and the `suspend` extension route took only a class, `String`, primitive or enum receiver even though `ByteArray`, a collection, a nullable interface and a value class already crossed as a parameter on the ordinary route. A property couldn't sit on `ByteArray`, a nullable collection or a nullable bound interface. A `suspend fun ...: Result<T>` had no binding on any owner. Now the rule is one sentence: an extension binds on every receiver the bridge can pass as a parameter, on the same wire.

```kotlin
class Bindle<T>(var top: T)

/** The extension's own `T` at the receiver's type argument. */
fun <T> Bindle<T>.unpack(): T = top

/** A star projection: a synthesized type parameter in C#. */
fun Bindle<*>.isPacked(): Boolean = top != null

/** A bare unbounded `T`: `extension<T>(T receiver)` on `ObjectExtensions`. */
val <T> T.label: String get() = "label:$this"

/** A `Result<T>` result: `Task<string>`, a failure faults the task. */
suspend fun Dozer.wakeOrFail(ok: Boolean): Result<String> {
  delay(1.milliseconds)
  return if (ok) {
    Result.success("$name is awake")
  } else {
    Result.failure(IllegalStateException("$name refuses to wake"))
  }
}

/** A class whose members are extensions: `groomhand.Brush(loafer, 3)` in C#. */
class Groomhand(val name: String) {
  fun Loafer.brush(strokes: Int): String = "${this@Groomhand.name} brushes $name $strokes times"

  /** A member extension property: `GetNick(Loafer receiver)`, Kotlin/JVM's own lowering. */
  val Loafer.nick: String get() = "${this@Groomhand.name}'s $name"
}
```

```csharp
using var kibble = new Bindle<string>("kibble");
using var empty = new Bindle<string?>(null);
kibble.Unpack();  // "kibble", T inferred from the receiver
empty.IsPacked(); // false, IsPacked<TBindle>(this Bindle<TBindle> receiver)
var tag = 42.Label; // "label:42", ObjectExtensions

using var oreo = new Loafer("Oreo");
using var mylo = new Loafer("Mylo");
await oreo.WakeOrFailAsync(true);  // "Oreo is awake"
await mylo.WakeOrFailAsync(false); // throws InvalidOperationException "Mylo refuses to wake"

using var hand = new Groomhand("Oreo");
hand.Brush(mylo, 3);  // "Oreo brushes Mylo 3 times"
hand.GetNick(mylo);   // "Oreo's Mylo"
hand.SetMood(mylo, 7);
```

A sync extension stays on the ADR-062 plan route; the own-`T` gate that admits a parameter now reads the receiver too, so `T Unpack<T>(this Bindle<T> receiver)` keeps the plan's type parameters and `where` clauses, and a generic property renders as a C# 14 `extension<T>(Bindle<T> receiver)` block. A bare `T` homes on `{FirstBound}Extensions` in the bound's namespace (`DozerExtensions`), an unbounded one on `ObjectExtensions`, one helper owning that key for every site. A receiver whose type arguments are all `*` gets a synthesized method type parameter named after the class (`IsPacked<TBindle>`, `Headcount<TList>`), the receiver position being the one place that's unambiguous. A `suspend` extension's receiver is the first parameter of the ADR-229 static route, lowered by the same shape a `suspend` parameter uses, and widening those shapes admits a plain interface, bound interface, value class, `Uuid`, `Instant`, `Duration`, `ByteArray`, collection and the nullables as a `suspend` parameter too, so a receiver is never accepted where the same parameter is refused. A sync extension returning `Flow`, `StateFlow` or `SharedFlow` rides the ADR-230 static flow route with the receiver crossing first.

A member extension binds as an instance method with the receiver first, named `receiver` (`hand.Brush(mylo, 3)`), Kotlin/JVM's own lowering, since C# only declares an extension method in a non-generic static class; a member extension property is a `GetX`/`SetX` pair taking the receiver, and a `Flow` typed one is a flow method. `suspend fun ...: Result<T>` binds as `Task<T>` on every `suspend` owner (class, sealed, top level, `object`, companion, enum, value class, extension): Kotlin calls `getOrThrow()` inside the coroutine, so a failure faults the `Task` through the usual exception mapping. No `TryXAsync` twin, a `Task` already is the try shape. Two generator bugs fell out on the way: the ADR-229 enum receiver `_async` export passed the raw ordinal instead of `Drowse.entries[receiver]`, and the nullable scalar or enum receiver's null branch had an operator-precedence bug (`if (has) X else null.loudly()`). The `SUSPEND` and `GENERIC` skip sentences stop listing an extension on another receiver as unsupported; an extension on an unexported receiver is still skipped, because it has no C# type to extend.
