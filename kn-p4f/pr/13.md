TITLE: Bind a generic value class under `?` and inside a collection (ADR-226)

A function's own `T` inside a generic value class was a named skip under `?` (`Sticker<T>?`) and inside a `List`, `Set` or `Map`. Under `?` the reason was real: `null` and `Sticker(null)` would share one null pointer. A star-projected `Sticker<*>` parameter was refused too, because it has no C# spelling. Now a nullable value class whose underlying can be null crosses as ADR-228's box handle, an own `T` inside the struct is a collection component, and `Sticker<*>` gets a synthesized method type parameter.

```kotlin
fun <T> maybeStick(value: T, present: Boolean): Sticker<T>? =
  if (present) Sticker(value) else null

fun <T> isAbsent(sticker: Sticker<T>?): Boolean = sticker == null

fun <T> stickAll(values: List<T>): List<Sticker<T>> = values.map { Sticker(it) }

fun treatState(treats: TreatCount?): String =
  if (treats == null) "no count" else treats.count?.toString() ?: "uncounted"

fun starred(sticker: Sticker<*>): String = "star ${sticker.value}"
```

```csharp
StickerGaps.MaybeStick<uint?>(null, present: false);             // null
StickerGaps.MaybeStick<uint?>(null, present: true)!.Value.Value; // null, inside a Sticker(null)
StickerGaps.IsAbsent<byte?>(new Sticker<byte?>(null));           // false
StickerGaps.StickAll(new ushort[] { 1, 2 });                     // [Sticker<ushort>(1), Sticker<ushort>(2)]
StickerGaps.TreatState(null);                                    // "no count"
StickerGaps.TreatState(new TreatCount(null));                    // "uncounted"
StickerGaps.Starred(new Sticker<string>("Oreo"));                // "star Oreo"
```

Every `V?` at these positions crosses as the box handle: a null pointer is `null`, a live handle is `V(null)` or a present value. That includes `Sticker<T>?` with `T : Any`, where an in-band null pointer would also have worked; one wire for every case was simpler. At a non-null outer, `TreatCount(Int?)` crosses as a has-value pair. `Starred<TSticker>(Sticker<TSticker> sticker)` is unconstrained; `withMethodTypeParameterConstraints` used to drop any type parameter beyond the declared ones, so that's fixed too. C# can't infer `T` through `Nullable<>`, so passing a `Sticker<byte?>` to a `Sticker<T>?` parameter needs the type argument (`IsAbsent<byte?>(...)`, CS0411 without it), and so does passing `null`. Generic top-level extensions now bind in general, any `fun <T> X.f()`, not only a value class receiver, which flipped two expectations (`structuralOnExtension` in `UnroutedPositionsTests`, `extended` in `Tier1MemberGenericMethodTest`).
