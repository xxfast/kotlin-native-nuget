- KSP incremental processing if build times become a concern on large libraries. - Hand-written C# shim escape hatch for API members outside the auto-bridgeable subset (spm4Kmp's bridge-folder model, synthesis D2)
- Local-feed dev loop: let a C# consumer iterate against a locally built `.nupkg` before publishing (KMMBridge-style dual flow, synthesis D6). The open part is cache-safe re-publishes of a changed `.nupkg`; see the [archive](docs/archive/roadmap.md)
- First-class Gradle publishing workflow for generated NuGet packages: a `publishNuget` task + DSL mirroring Gradle's Maven publishing APIs, so authors never invoke `dotnet nuget push` themselves ([archive](docs/archive/roadmap.md))
- Publish to GitHub Packages as a secondary registry, mirroring KStore. Worth it only as a mirror beside the primary registries, since GitHub Packages needs a token even to read public packages ([archive](docs/archive/roadmap.md))
- Forward un-skip/remap escape hatch: a Xamarin-`Metadata.xml`-style (or `@HiddenFromObjC`-style opt-out) mechanism to force-bind or remap a construct [ADR-064](docs/adr/064-forward-unsupported-declaration-diagnostics.md) would otherwise skip. Deferred by ADR-064's Scope; today the diagnostic's hint text names the hand-written-adapter workaround instead, the same choice ADR-043 made for reverse

That remaining layer's design is in [`docs/backlog/reverse-dogfooding-layer2-layer3-design.md`](docs/backlog/reverse-dogfooding-layer2-layer3-design.md)
- [ADR-154](docs/adr/154-forward-dependency-type-admission.md)'s `admit(...)` was never exercised against a real published klib (ktor's `Url`/`LogLevel`, kermit's `Severity`, the shapes it was designed around); only the `:test-models` fixture proves it. Forward direction's analogue of the reverse-bridge item above
- Opt-in compiled-assembly packaging mode: ship the C# shim as a prebuilt `lib/<tfm>/*.dll` instead of the [ADR-050](docs/adr/050-end-to-end-packaging-integration.md) source shim. Flagged by an external integration report (2026-08-20); needs its own ADR, and cuts against the no-.NET-SDK goal ([archive](docs/archive/roadmap.md))
- Expose Kotlin `Job` as a mapped C# type so cancellation can be tied to the job directly (e.g., `job.Cancel()`) instead of requiring a pre-created `CancellationTokenSource`
- NativeAOT compatibility for the generated bindings ([ADR-038](docs/adr/038-aot-compilation.md)). Reflection-free generic dispatch shipped via [ADR-094](docs/adr/094-reflection-free-generic-dispatch.md); the AOT smoke-test lane and the `[UnmanagedCallersOnly]` callback port are real roadmap items now, leaving only the interop-dialect switch below ([archive](docs/archive/roadmap.md))

- Swap the forward *reader* from KSP to a K2/IR compiler plugin, **if and when the compiler plugin API stabilizes**. Reader only; the Gradle plugin's orchestration stays regardless. Full cost/benefit writeup in the [archive](docs/archive/roadmap.md)
