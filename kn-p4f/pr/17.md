TITLE: Carry stdlib and value class types on `suspend` and `Flow` (ADR-240)

ADR-235 bound these types on the ordinary route, but the `suspend` and `Flow` routes classify their own parameters, results and elements, and refused every one of them as a parameter. A bare `Instant`, `Duration` or `Uuid` result or `Flow` element was worse: it fell through to the user-type speller and failed the whole module. A static suspend receiver of any of these types was a named skip. Now `Instant`, `Duration`, `Uuid`, `ByteArray`, a plain interface and a value class over any underlying cross every async position the ordinary route already does.

```kotlin
value class PostBundle(val letters: List<String>) {
  init {
    require(letters.size <= 3) { "a bundle holds at most three letters" }
  }

  suspend fun top(): String {
    delay(1.milliseconds)
    return letters.first()
  }
}

suspend fun packPost(bundle: PostBundle): PostBundle {
  delay(1.milliseconds)
  return PostBundle(bundle.letters.sorted())
}

fun padStream(pads: ByteArray, count: Int): Flow<ByteArray> = flow {
  repeat(count) { emit(pads + it.toByte()) }
}

suspend fun Instant.nudge(minutes: Int): Instant {
  delay(1.milliseconds)
  return this + minutes.minutes
}
```

```csharp
(await PawpostSample.PackPostAsync(new PostBundle(new List<string> { "card", "bill" }))).Letters; // ["bill", "card"]
await new PostBundle(new List<string> { "bill", "card" }).TopAsync(); // "bill"
await default(PostBundle).TopAsync(); // throws ArgumentException

using KotlinFlow<byte[]> pads = PawpostSample.PadStream(new byte[] { 2 }, 2);
await Drain(pads); // [[2, 0], [2, 1]]

await OreoPostmark.NudgeAsync(5); // OreoPostmark.AddMinutes(5)
```

Parameters cross on the ordinary route's wire, and a value class is seen through to its innermost underlying, so `PostPrint(ByteArray)` crosses exactly as a `ByteArray` does. Kotlin reads each slot before the coroutine launches, so C# releases a minted handle in the `finally` as soon as the extern returns. A failing `init` on a value-class parameter throws `KotlinArgumentException` from the call with no `Task`; on a receiver it faults the `Task` instead. Value classes over these underlyings now get the box/unbox pair, so they work at every erased position (`Flow` element, awaited result, `MutableStateFlow` write), and `Mutable*Flow` of a bare `ByteArray`, collection or interface is settable. A `byte[]` or collection struct now compares by content through a generated `Equals(V)` and `GetHashCode()` (list in order, set ignoring order), so it works as a dictionary key; an interface struct keeps reference equality. A class owner mints its coroutine scope on its first `suspend` call, so the leak rows warm it before the baseline.
