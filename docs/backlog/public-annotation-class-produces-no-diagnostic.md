# A public `annotation class` produces no diagnostic at all, forward direction

**A public `annotation class` (whether `expect` or ordinary) is silently absent from the generated C#, with no `SKIPPED_*` diagnostic and no warning of any kind.** The forward direction has no route for `ClassKind.ANNOTATION_CLASS` at all: `rootClasses` requires `classKind == CLASS`, and a grep of `nuget-processor/src/main` for `ANNOTATION_CLASS` returns zero hits. An ordinary `annotation class` is therefore already outside the export set before ADR-064's skip-with-a-name policy would ever see it; an `expect annotation class` is filtered one line earlier by the `isExpect` guard and is otherwise identical. It went unnoticed because ADR-064's diagnostic coverage was built out kind-by-kind as each kind's route was added, and annotation classes never got a route to begin with, so there was never a diagnostic to omit in the first place, only an absence to notice by reading. Verified by reading, no fixture: an absence assertion on an un-routed kind pins nothing useful. Discovered alongside [ADR-074](https://github.com/xxfast/kotlin-native-nuget/blob/main/docs/adr/074-expect-actual-declarations.md)'s 2026-09-05 amendment, which settled `expect annotation class` as "not applicable" for the same underlying reason.
