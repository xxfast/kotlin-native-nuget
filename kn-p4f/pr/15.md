TITLE: Bind a lambda property on every owner as a BCL delegate (ADR-236)

A lambda property only bound on an ordinary class and a sealed arm, non-null and get-only, typed as a wrapper (`KotlinFunc<A, R>`, `KotlinAction<A>`, `KotlinSuspendFunc<A, R>`). An interface, `object`, companion, the top level, an enum, a generic class and a sealed base skipped it with `SKIPPED_UNSUPPORTED_PROPERTY`, a nullable one was refused, and a `var` got no setter. A wrapper type can't take a setter either: C# never applies a user-defined conversion to a lambda literal (CS1660). Now every owner binds it as the BCL delegate, nullable and `suspend` included, and a `var` takes any C# delegate.

```kotlin
object Landing {
  var format: (Double) -> String = { metres -> "Oreo ran $metres m" }

  var onBump: ((String) -> String)? = null

  var onSettle: (suspend (String) -> String)? = null

  fun describe(metres: Double): String = format(metres)

  fun bump(who: String): String = onBump?.invoke(who) ?: "nobody bumped $who"

  suspend fun settle(who: String): String = onSettle?.invoke(who) ?: "$who never settled"
}
```

```csharp
Func<double, string> original = Landing.Format;
original.Invoke(2.5); // "Oreo ran 2.5 m"

Landing.Format = metres => $"Mylo timed {metres} m";
Landing.Describe(4.0); // "Mylo timed 4 m"

Landing.OnBump = who => $"Oreo bumped into {who}";
Landing.Bump("Mylo"); // "Oreo bumped into Mylo"
Landing.OnBump = null;

Landing.OnSettle = async (who, token) =>
{
    await Task.Delay(1, token);
    return $"{who} curled up on the stairs";
};
await Landing.SettleAsync("Oreo"); // "Oreo curled up on the stairs"
```

**Breaking** for every lambda property that already bound:

| Before | After |
|---|---|
| `KotlinFunc<A, R>` property | `Func<A, R>` |
| `KotlinAction<A>` property | `Action<A>` |
| `KotlinSuspendFunc<A, R>` / `KotlinSuspendAction<A>` property | `Func<A, CancellationToken, Task<R>>` / `Func<A, CancellationToken, Task>` |
| `using var f = obj.Prop;` | `var f = obj.Prop;` (a delegate isn't `IDisposable`) |
| `await f.InvokeAsync(args)` | `await f.Invoke(args, token)`, `CancellationToken.None` when there's none |
| `typeof(KotlinFunc<CamId, Snapshot>)` as the property type | `typeof(Func<CamId, Snapshot>)` |
| sealed-arm getter swallows the error slot (`out _`) | sealed-arm getter carries it, so a throwing getter raises `KotlinException` |

A function returning a lambda (`fun adder(n: Int): (Int) -> Int`) still returns the wrapper; only the property type changed. Each getter read mints a fresh handle the delegate's target releases on collection, so there's nothing to dispose. A delegate that came from a Kotlin getter goes back as the same Kotlin lambda; a C# one is minted through three new fixed-ABI runtime exports (`nuget_func_from_managed`, `nuget_suspend_func_from_managed`, `nuget_handle_retain`), and a replaced or cleared one becomes collectable. An enum body property can't be a C# property, so it's a `Name()` extension plus `SetName(...)` for a `var` (`Stride.Gallop.SetOnTrip(f)`). Static placement follows the owner: the static class for an `object` and the top level, the owning class for a companion, `{Enum}Extensions` for an enum companion.
